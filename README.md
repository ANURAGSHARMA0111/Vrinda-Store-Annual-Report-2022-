# 📊 Vrinda Store Annual Report 2022 – Excel Dashboard

## 📌 Project Overview

The **Vrinda Store Annual Report 2022** is an interactive Excel dashboard created to analyze store sales, customer demographics, order status, sales channels, and state-wise performance.

The dashboard provides a visual summary of the store's performance and helps identify important sales and customer trends.

---

## 🎯 Project Objective

The main objective of this project is to analyze the Vrinda Store's 2022 sales data and understand:

- Sales performance
- Order trends
- Customer gender distribution
- Order status
- Top-performing states
- Customer age groups
- Sales channels
- Category performance

---

## 📊 Dashboard Analysis

### 1. Orders vs Sales

This chart compares the **number of orders** with the **sales amount** to understand the relationship between sales and order volume.

### 2. Sales: Men vs Women

This chart shows the sales contribution of **male and female customers** and helps understand which customer segment contributes more to sales.

### 3. Order Status

This visualization shows the distribution of orders based on their status, such as:

- Delivered
- Cancelled
- Returned

### 4. Top 5 States

The dashboard displays the **Top 5 states** based on sales performance.

This helps identify the states contributing the most to the store's sales.

### 5. Order: Age vs Gender

This chart analyzes orders based on **customer age group and gender**, helping understand the customer demographics.

### 6. Orders by Channel

This visualization shows the distribution of orders across different sales channels, including:

- Ajio
- Amazon
- Flipkart
- Meesho
- Myntra
- Nalli
- Others

---

## 🎛️ Interactive Filters

The dashboard contains interactive slicers that allow users to filter the report by:

- **Month**
- **Category**
- **Channel**

These filters make the dashboard interactive and allow users to perform focused analysis.
